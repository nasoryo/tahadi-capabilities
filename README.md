# 🎯 مشروع منصة "تحدي القدرات" - نسخة الإنتاج الجاهزة للنشر

نظام احترافي لإدارة ومتابعة درجات طلاب اختبارات القدرات، وحساب الترتيب، المجموع، والمتوسط تلقائياً.

---

## 🚀 المميزات الرئيسية:
- **عرض عام للطلاب (روابط الجوال):** عرض تفاعلي للترتيب العام وحسب الفصول (أ، ب، ج، د)، محرك بحث فورية، وميداليات للمراكز الأولى 🥇🥈🥉.
- **حماية لوحة الإدارة:** كلمة مرور مخصصة لحماية تعديل البيانات وحذفها.
- **تحديث تلقائي:** إعادة حساب الترتيب والمعدلات فور إدخال أي درجة.
- **قاعدة بيانات دائمة (SQLite):** مهيأة مع إمكانية التخزين الدائم على خوادم الاستضافة.

---

## 🌐 دليل النشر خطوة بخطوة على Render (Render.com)

### 1️⃣ الخطوة الأولى: تجهيز مستودع Git (GitHub)
1. قم بإنشاء حساب على [GitHub.com](https://github.com) إذا لم يكن لديك حساب.
2. أنشئ المستودع الجديد (Repository) باسم `qudrat-challenge`.
3. ارفع كافة ملفات هذا المشروع إلى المستودع.

### 2️⃣ الخطوة الثانية: النشر على Render
1. سَجّل الدخول إلى [Render.com](https://render.com).
2. اضغط على زر **New +** ثم اختر **Web Service**.
3. قم بربط حساب GitHub واختر المستودع `qudrat-challenge`.
4. اضبط الإعدادات التالية:
   - **Name:** `qudrat-challenge` (أو أي اسم تفضله)
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** `Free`

### 3️⃣ الخطوة الثالثة: ضبط المتغيرات البيئية (Environment Variables)
في صفحة إعدادات الخدمة على Render، انتقل إلى قسم **Environment**:
أضف المتغيرات التالية:
- `ADMIN_PASSWORD` = `كلمة_المرور_التي_تفضلها_للإدارة`
- `DB_PATH` = `/var/data/qudrat.db` *(في حال استخدام قرص التخزين الدائم Persistent Disk)* أو اتركها افتراضية `./data/qudrat.db`.

### 4️⃣ الخطوة الرابعة (موصى بها): تفعيل التخزين الدائم (Persistent Disk)
لضمان عدم مسح درجات الطلاب عند إعادة تشغيل خادم Render المجاني:
1. في لوحة Render الخدمة الخاصة بك، انتقل إلى **Disks**.
2. اضغط **Add Disk**.
3. اضبط الاسم على `qudrat-data` والمسار Mount Path على `/var/data`.
4. تأكد أن المتغير البيئي `DB_PATH` مظبوط على `/var/data/qudrat.db`.
